Duel World (ลูกผสม Master Duel + Duel Links) — คู่มือย่อ
=====================================================

เริ่มเล่น
- เปิด EDOPro-Story.exe > ปุ่ม "Duel World ★" ในเมนูหลัก
- ครั้งแรกจะให้เลือกเด็คเริ่มต้น 1 จาก 3: Blue-Eyes / Dark Magician / Red-Eyes
- หลังเลือก ระบบ "คลังการ์ด" จะเปิดทั้งเกม: เด็คใช้ได้เฉพาะการ์ดที่มีในคลัง
  (เด็คเก่าของคุณจะขึ้นการ์ดสีแดง = ยังไม่มีการ์ดใบนั้น)

แท็บใน Duel World
1) นักสู้สุ่ม  — สุ่มคู่ต่อสู้จากบทที่ปลดล็อคแล้ว ชนะได้ทอง/เพชร + ดรอปการ์ด/ไอเท็ม
2) ร้านค้า    — ซื้อแพ็ค (ภาคละ 1 แพ็ค + Staples) 1 หรือ 10 แพ็ค ใช้เพชร
3) พ่อค้าการ์ด — ขายการ์ดเจาะจงด้วยทอง เปลี่ยนสต็อกทุกวัน (ใช้ไอเท็มรีเฟรชได้)
4) ไอเท็ม     — ตั๋วแพ็ค, ถุงเพชร/ทอง, รีเฟรชพ่อค้า, เรียกนักสู้ใหม่

ความแรร์: N (เทา) / R (ฟ้า) / SR (ทอง) / UR (รุ้ง)
- แพ็คละ 8 ใบ ใบสุดท้ายการันตี SR ขึ้นไป
- เปิดแพ็ค: คลิกซ้าย = ถัดไป, คลิกขวา = ข้ามทั้งหมด

เนื้อเรื่อง: ชนะครั้งแรกได้ 150 เพชร + 800 ทอง + การ์ด SR+ + ตั๋วแพ็คของภาคนั้น

ลากไปตี (เหมือน Master Duel)
- ใน Battle Phase กดค้างที่มอนสเตอร์ของเรา แล้วลากไปปล่อยบนมอนสเตอร์ฝั่งตรงข้าม
- ลากขึ้นไปที่ว่าง = โจมตีตรง (ถ้าทำได้)

แก้ค่าเองได้ (เปิดด้วย Notepad)
- story\world\world.json  : เงินเริ่มต้น, เรทดรอป, ราคา, ไอเท็ม, เด็คเริ่มต้น
- story\world\packs.json  : รายชื่อแพ็คและการ์ดในแพ็ค
- story\world\rarity.json : กำหนดความแรร์เองรายใบ เช่น "89631139": "UR"
- story\world\save.json   : เซฟของคุณ (ลบไฟล์นี้ = เริ่มใหม่)

ภาพตัวละคร (story\portraits\)
- ภาพที่ใส่มาเป็นภาพเงาออริจินัล (ไม่ใช่อาร์ตต้นฉบับจากอนิเมะ)
- อยากเปลี่ยน: วางไฟล์ .png ทับชื่อเดิม เช่น kaiba.png (แนะนำพื้นหลังโปร่งใส สัดส่วน 2:3 เช่น 600x900)
- ผูกชื่อตัวละคร -> ไฟล์ ได้ใน story\portraits\portraits.json  ("player" = รูปของคุณ)

ดวลในเนื้อเรื่อง/นักสู้สุ่ม: หน้า VS > ทอยเหรียญ > DUEL START > ... > VICTORY/LOSE แล้วกลับเมนูอัตโนมัติ (ไม่มีถามดวลซ้ำ/เซฟรีเพลย์ — รีเพลย์ล่าสุดอยู่ที่ replay\_LastReplay)

อัปเดตครั้งถัดไป: ไฟล์จะมาที่ story\_update\ แล้วเกมจะอัปเดตตัวเองตอนเปิด ไม่ต้องทำอะไร
